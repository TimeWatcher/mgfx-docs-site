## Plugins and Redistribution

A plugin that uses only MGFX public interfaces and contains no MGFX code is not
an MGFX-derived portion and may use another license. It still cannot use MGFX in
connection with a paid plugin without separate authorization.

When distributing MGFX or an MGFX-derived portion, keep the license and
attribution notices, mark modified files, and apply the same license to the
MGFX-derived portion. Independent free plugins are not required to adopt the
MGFX license.
